# Gabriel Manosalvas - Personal Brand Landing Page

Este proyecto es una Landing Page profesional y responsiva desarrollada como portafolio y marca personal. Construida estrictamente con estándares semánticos modernos y diseño libre de frameworks externos.

## 🎯 Tecnologías Utilizadas
- **HTML5:** Estructura 100% semántica (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`).
- **CSS3:** Diseño responsivo (Mobile-First y Media Queries), CSS Grid, Flexbox y selectores avanzados.
- **Docker:** Contenedorización para despliegue ágil.

## 🎨 Identidad Visual
Se utilizó la paleta "Trust & Code":
- Primario: `#0F172A` (Confianza corporativa)
- Acento: `#38BDF8` (Innovación tecnológica)
- Tipografías: *Poppins* (Encabezados) e *Inter* (Cuerpo de texto).

## 🚀 Instrucciones de Ejecución

### Ejecución Local (Sin Docker)
1. Clona este repositorio: `git clone https://github.com/tu-usuario/personal-brand-landing.git`
2. Abre el archivo `index.html` en tu navegador web preferido.
